### Criteria
- US HQ + US-built
- **USAbench (v2, 0–100)**: open-weights sovereignty + recency + transparency, not raw capability
- **100 = fully open AND US-made**: only clean `fullOpen` US models (no foreign teacher, not closed) can hit 100; everyone else caps at 99, and bonuses cap before penalties
- Tiers: **95–100** ⭐⭐⭐ • **80–94** ⭐⭐ • **60–79** ⭐
- **Foreign weight base → ❌ 0**: Qwen / GLM / Kimi / DeepSeek foundations (no partial credit)
- **Foreign teacher → ⚠️ soft −15**: own pretrain + foreign SFT/synth teachers noted, not hard-zeroed (e.g. Inkling)
- Decay: 0 (0–3mo) • 3 • 8 • 15 • 22 (19+). +5 fullOpen, +3 permissive, −10 closed
- Scores from `data/usabench.json` — run `node scripts/usabench.mjs` after edits
- Closed models (Claude, GPT, Grok) can be great — just not sovereign-open; stale weights fall fast
